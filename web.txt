SYSTEM REQUIREMENTS SPECIFICATION (SRS)
PROJECT: GLOBAL SUPPLY CHAIN RISK INTELLIGENCE PLATFORM
=============================================================================

1. DESKRIPSI PROYEK
Sistem ini adalah platform pemantauan risiko rantai pasok global berbasis analitik data dan integrasi multi-API[cite: 1, 2]. Platform ini ditujukan untuk memantau kondisi cuaca, ekonomi, gangguan transportasi, dan geopolitik guna mendukung pengambilan keputusan bisnis logistik[cite: 5, 6, 7].

2. TECH STACK (TEKNOLOGI YANG DIGUNAKAN)
Pendekatan: Full Stack Development dengan pemisahan Frontend dan Backend via REST API[cite: 10, 231].

Backend:
- Bahasa: PHP [cite: 28]
- Framework: Laravel [cite: 29]
- Database: MySQL [cite: 30]

Frontend:
- UI Framework: Bootstrap 5 [cite: 32]
- Interaktivitas: Vanilla JavaScript ES6 & AJAX / Fetch API [cite: 33, 34]
- Visualisasi Data: Chart.js [cite: 36]
- Pemetaan Geospatial: Leaflet.js [cite: 37] & OpenStreetMap [cite: 88, 89]

Deployment:
- Version Control: GitHub [cite: 41]
- Containerization: Docker (Opsional) [cite: 40]

3. INTEGRASI API EKSTERNAL (GRATIS)
Sistem harus mengonsumsi data dari 6 API eksternal berikut[cite: 241, 42]:
1. Open-Meteo API: Untuk data cuaca (suhu, hujan, angin, badai)[cite: 43, 44, 48, 49, 50, 51].
2. World Bank API: Untuk data makroekonomi (GDP, Inflasi, Populasi, Ekspor/Impor)[cite: 53, 57, 58, 59, 60].
3. REST Countries API: Untuk profil negara (Mata uang, wilayah, bahasa)[cite: 61, 65, 66, 67, 68].
4. ExchangeRate API: Untuk kurs mata uang real-time[cite: 69, 73].
5. World Port Index Dataset (CSV/API publik): Sebagai ganti Marine Traffic untuk data lokasi pelabuhan publik[cite: 74, 75, 76, 79, 80].
6. GNews API: Untuk agregasi artikel berita ekonomi, logistik, dan geopolitik[cite: 82, 84, 86, 87].

4. FITUR UTAMA DASHBOARD
Frontend harus memiliki 10 fitur utama berikut[cite: 90]:
- Global Country Dashboard: Menampilkan detail spesifik satu negara (GDP, inflasi, cuaca saat ini, mata uang)[cite: 91, 98, 99, 100, 102, 103].
- Risk Scoring Engine: Menampilkan skor risiko negara[cite: 104, 106].
- Global Weather Monitoring: Peta dunia yang merender data hujan/badai/angin per negara[cite: 115, 116, 117, 118].
- Currency Impact Dashboard: Menampilkan tren nilai tukar mata uang menggunakan Chart.js[cite: 120, 122, 123, 124].
- News Intelligence: Menampilkan feed berita spesifik logistik, ekonomi, dan perdagangan[cite: 125, 127, 129].
- Port Location Dashboard: Peta interaktif dengan fitur pencarian pelabuhan/negara[cite: 131, 132, 134, 136, 137].
- Data Visualization Dashboard: Menampilkan grafik tren GDP, inflasi, kurs, dan risiko[cite: 138, 140, 141, 142, 143].
- Country Comparison Engine: Fitur komparasi indikator antar dua negara (misal: Germany vs Australia)[cite: 144, 145, 146].
- Favorite Monitoring List: Watchlist penyimpan negara favorit user[cite: 152, 153].
- Admin Dashboard: Untuk kelola user, artikel, dan dataset pelabuhan[cite: 154, 155, 156, 157, 158].

5. LOGIKA BISNIS & ALGORITMA (TUGAS BACKEND DEVELOPER)
Tidak diperbolehkan menggunakan layanan AI berbayar[cite: 159]. Developer harus membangun algoritma di dalam PHP:

A. Lexicon Based Sentiment Analysis [cite: 160, 161, 162, 163]
- Sistem membaca teks artikel dari GNews API.
- Mencocokkan kata dengan tabel database "positive_words" dan "negative_words"[cite: 169, 171, 178].
- Jika skor positif > negatif = Sentimen "Positive"[cite: 187, 188, 189, 192, 196, 209, 210, 211].

B. Supply Chain Risk Prediction [cite: 212]
- Menggunakan Weighted Risk Model / Simple Scoring Algorithm[cite: 213, 214, 216].
- Mengalkulasi persentase pembobotan (Contoh: Cuaca 30%, Inflasi 20%, Berita 40%, Kurs 10%) untuk menghasilkan Total Risk Score (misal: 28%)[cite: 218, 219, 220, 221, 222].
